# DB Relay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows Tauri desktop application that stores database settings and reusable migration flows, then executes ordered Oracle upserts with safe transaction and user-directed recovery behavior.

**Architecture:** React/TypeScript renders the local desktop UI and calls a narrow Tauri command API. Rust owns the domain model, migration state machine, mapping validation, connector contracts, persistence, credential handling, and Oracle implementation. The UI never accesses database drivers or secrets directly.

**Tech Stack:** Tauri 2, Rust stable, React, TypeScript, Vite, pnpm, Vitest, React Testing Library, `rusqlite`, `keyring`, `oracle-rs`, `tokio`.

## Global Constraints

- Target Windows desktop through Tauri 2; use a React/TypeScript UI and a Rust core.
- First database connector is Oracle; future database support must require only a connector implementation and registry entry.
- Persist metadata locally in SQLite and secrets only through Windows Credential Manager via a credential reference.
- A flow stores DB-setting references, ordered query steps, and transaction policy; it never stores credentials.
- Match source column aliases to target named bind parameters case-insensitively; block an execution before it starts if validation fails.
- `all_or_nothing` rolls back every target change on any failure.
- `commit_successes` commits each successful query. A failed query rolls back only itself and pauses for **edit and retry**, **skip and continue**, or **stop**.
- Record step results and recovery choices without persisting secrets, bind values, or source rows.
- Apply the warm cream, coral, and dark-surface language in `DESIGN-claude.md`.
- Preserve the documented dependency direction: UI → application → domain ports; infrastructure and connectors implement ports.
- All behavior is implemented test-first; every code task below starts with a focused failing test.

- [ ] **Step 3: Implement the smallest pure domain model and mapper**

Implement a `Value` enum for null, string, integer, decimal, boolean, timestamp, and bytes; normalize only keys with `to_ascii_uppercase`. Make the bind scanner skip quoted string literals and SQL `--`/`/* */` comments, accept only `:[A-Za-z_][A-Za-z0-9_$#]*`, and deduplicate repeated parameters while preserving first occurrence order.

```rust
pub fn map_row(row: &Row, binds: &[String]) -> Result<NamedRow, MappingError> {
    let normalized = row.normalized_index()?;
    binds.iter().map(|bind| {
        normalized.get(&bind.to_ascii_uppercase())
            .cloned()
            .map(|value| (bind.clone(), value))
            .ok_or_else(|| MappingError::MissingSourceColumn { parameter: bind.clone() })
    }).collect()
}
```
