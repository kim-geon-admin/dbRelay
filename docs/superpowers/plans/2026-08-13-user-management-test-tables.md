# User Management Test Tables Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one Oracle DDL script that creates matching source and target user-management table sets for future DB Relay data setup.

**Architecture:** Keep the fixture self-contained in `data/user-management-tables.sql`. The source and target sets use the same column order, datatypes, defaults, and logical constraints; their `SRC_` and `TGT_` prefixes prevent collisions when both sets exist in one schema. No application source, sample data, cleanup operation, or generic SQL capability changes.

**Tech Stack:** Oracle SQL DDL, PowerShell static validation, Git.

## Global Constraints

- Target platform is Oracle, using `NUMBER`, `VARCHAR2`, `CHAR`, `TIMESTAMP`, and `GENERATED BY DEFAULT AS IDENTITY`.
- Add only table DDL now; do not include `INSERT`, `MERGE`, `UPDATE`, `DELETE`, `DROP`, `TRUNCATE`, or anonymous PL/SQL.
- Create six tables, each with fewer than ten columns.
- `SRC_USER_ADDRESSES.USER_ID` and `TGT_USER_ADDRESSES.USER_ID` must reference their corresponding user table.
- Preserve unrelated uncommitted work.

- [ ] **Step 2: Add the minimal DDL fixture**

Create `data/user-management-tables.sql` with only the following six table definitions. Keep the source tables before their target equivalents so each parent is created before its child.

```sql
CREATE TABLE SRC_USERS (
  USER_ID NUMBER(19) GENERATED BY DEFAULT AS IDENTITY,
  LOGIN_ID VARCHAR2(50 CHAR) NOT NULL,
  DISPLAY_NAME VARCHAR2(100 CHAR) NOT NULL,
  EMAIL VARCHAR2(254 CHAR) NOT NULL,
  USER_STATUS VARCHAR2(20 CHAR) DEFAULT 'ACTIVE' NOT NULL,
  REGISTERED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_SRC_USERS PRIMARY KEY (USER_ID),
  CONSTRAINT UQ_SRC_USERS_LOGIN UNIQUE (LOGIN_ID),
  CONSTRAINT UQ_SRC_USERS_EMAIL UNIQUE (EMAIL),
  CONSTRAINT CK_SRC_USERS_STATUS CHECK (USER_STATUS IN ('ACTIVE', 'INACTIVE', 'SUSPENDED'))
);

CREATE TABLE SRC_USER_ADDRESSES (
  ADDRESS_ID NUMBER(19) GENERATED BY DEFAULT AS IDENTITY,
  USER_ID NUMBER(19) NOT NULL,
  ADDRESS_TYPE VARCHAR2(20 CHAR) NOT NULL,
  POSTAL_CODE VARCHAR2(20 CHAR) NOT NULL,
  CITY VARCHAR2(100 CHAR) NOT NULL,
  ADDRESS_LINE1 VARCHAR2(200 CHAR) NOT NULL,
  IS_PRIMARY CHAR(1 CHAR) DEFAULT 'N' NOT NULL,
  CREATED_AT TIMESTAMP DEFAULT SYSTIMESTAMP NOT NULL,
  CONSTRAINT PK_SRC_USER_ADDRESSES PRIMARY KEY (ADDRESS_ID),
  CONSTRAINT FK_SRC_ADDR_USER FOREIGN KEY (USER_ID) REFERENCES SRC_USERS (USER_ID),
  CONSTRAINT CK_SRC_ADDR_PRIMARY CHECK (IS_PRIMARY IN ('Y', 'N'))
);

CREATE TABLE SRC_USER_CONTACT_EXPORT (
  CONTACT_EXPORT_ID NUMBER(19) GENERATED BY DEFAULT AS IDENTITY,
  USER_ID NUMBER(19) NOT NULL,
  ADDRESS_ID NUMBER(19) NOT NULL,
  LOGIN_ID VARCHAR2(50 CHAR) NOT NULL,

  ADDRESS_TYPE VARCHAR2(20 CHAR) NOT NULL,

  POSTAL_CODE VARCHAR2(20 CHAR) NOT NULL,
  CONSTRAINT PK_SRC_USER_CONTACT_EXPORT PRIMARY KEY (CONTACT_EXPORT_ID)

CREATE TABLE TGT_USERS (

CREATE TABLE TGT_USER_ADDRESSES (
```

- [ ] **Step 3: Run the fixture-contract check after the DDL exists**

```powershell
$ddl = Get-Content -Raw 'data/user-management-tables.sql'

  if ($ddl -notmatch [regex]::Escape($reference)) { throw "Missing foreign key reference: $reference" }
}
```
