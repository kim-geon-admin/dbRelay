# Oracle 오류 코드 한글 표시

DB Relay는 Oracle 드라이버의 원문 오류 메시지를 로그, 실행 이력, 복구 대화상자에 표시하지 않는다. 원문에는 접속 정보나 SQL·바인드 관련 민감 정보가 포함될 수 있기 때문이다. 대신 오류 코드와 아래의 한글 이름·조치를 표시한다.

| 오류 코드 | 한글 이름 | 사용자 안내 |
| --- | --- | --- |
| ORA-00001 | 고유 제약 조건 위반 | 동일한 값이 이미 존재합니다. 중복 키 또는 고유 인덱스를 확인하세요. |
| ORA-00942 | 테이블 또는 뷰가 존재하지 않음 | 객체 이름, 스키마, 그리고 조회 권한을 확인하세요. |
| ORA-01017 | 사용자 이름 또는 비밀번호가 올바르지 않음 | 접속 계정 정보와 계정 상태를 확인하세요. |
| ORA-01031 | 권한 부족 | 실행 계정에 필요한 객체 권한이 있는지 확인하세요. |
| ORA-01400 | NULL 값을 삽입할 수 없음 | 필수 컬럼에 값이 매핑되었는지 확인하세요. |
| ORA-02291 | 상위 키를 찾을 수 없음 | 참조 대상의 상위 데이터가 먼저 존재하는지 확인하세요. |
| ORA-02292 | 하위 레코드가 존재함 | 참조 중인 하위 데이터를 먼저 처리하세요. |
| ORA-03113 | 통신 채널 연결 종료 | 데이터베이스 연결이 끊겼습니다. 네트워크와 데이터베이스 상태를 확인하세요. |
| ORA-12154 | 접속 식별자를 해석할 수 없음 | 호스트, 포트, 서비스 이름 설정을 확인하세요. |
| ORA-12514 | 리스너가 요청한 서비스를 알 수 없음 | 서비스 이름과 리스너 등록 상태를 확인하세요. |
| ORA-12541 | 리스너가 없음 | 호스트, 포트, 그리고 Oracle 리스너 실행 상태를 확인하세요. |
| ORA-28000 | 계정 잠김 | Oracle 관리자에게 계정 잠금 해제를 요청하세요. |
| ORA-20000 | 애플리케이션 오류 | 데이터베이스의 애플리케이션 오류 로그를 확인하세요. |

## 모든 ORA 코드의 기본 한글화

Oracle 오류 카탈로그는 릴리스별로 수천 개의 코드와 운영체제·옵션별 메시지를 포함한다. DB Relay는 목록에 없는 어떤 형식의 `ORA-xxxxx` 코드도 원문 드라이버 메시지 대신 아래 코드 대역의 한글 오류 분류와 안전한 안내를 표시한다.

| 코드 대역 | 기본 한글 오류 이름 |
| --- | --- |
| ORA-00000–ORA-00899 | Oracle 인스턴스 오류 |
| ORA-00900–ORA-01499 | SQL 구문 또는 실행 오류 |
| ORA-01500–ORA-02098 | 데이터베이스 저장소 또는 트랜잭션 오류 |
| ORA-02100–ORA-04999 | Oracle SQL 실행 오류 |
| ORA-05000–ORA-09999 | Oracle 시스템 오류 |
| ORA-10000–ORA-19999 | SQL 실행 오류 |
| ORA-20000–ORA-32799 | 애플리케이션 또는 SQL 실행 오류 |
| ORA-32800–ORA-59999 | Oracle 기능 실행 오류 |
| ORA-60000–ORA-99999 | Oracle 데이터베이스 오류 |

코드별 한글 이름과 조치는 `src/lib/oracleErrors.ts`에 저장한다. Oracle 공식 Error Help는 코드별 메시지·원인·조치를 제공하며, 새 코드가 운영에서 확인되면 해당 공식 문서를 기준으로 코드별 항목을 추가한다. 이 기본 대역 처리는 모든 형식의 `ORA-xxxxx` 코드가 영어 원문 로그로 노출되지 않도록 보장한다.
